# Simple step-by-step setup guide

This is the easy version of the website. You only need to understand five HTML pages, one CSS file and one short JavaScript file.

## 1. The code files

| File | What it does |
|---|---|
| `index.html` | Home page and HIIT video. |
| `hypertrophy.html` | Muscle-growth information, image, list and table. |
| `recovery.html` | Recovery and ice-bath information. |
| `contact.html` | Contact form and Google Map. |
| `validation.html` | Sources, W3C notes and grading evidence. |
| `assets/css/style.css` | All colours, layout and mobile styling. |
| `assets/js/site.js` | The one show/hide tip button. |

Do not rename the `assets` folder. The website needs it for its styles and images.

## 2. Test it on your computer

1. Open the `forge-simple-hypertrophy-site` folder.
2. Double-click `index.html`.
3. Click every navigation link.
4. On Recovery, click **Show one simple recovery tip**.
5. On Contact, press **Check my form** with blank fields to see the browser validation.
6. Make your browser window narrow. The pages should stack into a mobile-friendly layout.

## 3. Make small personal edits

1. Search each HTML file for `Your Name` and change it to your own name.
2. Read the main paragraphs and change a few phrases so they sound like you.
3. Keep the safety and source links on the Recovery page.
4. Save the file and refresh the browser to see the change.

## 4. Upload to GitHub

1. Go to [GitHub](https://github.com/) and sign in.
2. Click **+**, then **New repository**.
3. Call it `forge-fitness` and choose **Public**.
4. Click **Create repository**.
5. Choose **Add file → Upload files**.
6. Upload everything inside this folder, especially the `assets` folder and all five HTML files.
7. Click **Commit changes**.

## 5. Make the live website

1. In the GitHub repository, open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder.
4. Click **Save**.
5. Wait a few minutes. Your link will look like:

   `https://your-github-username.github.io/forge-fitness/`

6. Open the link and test every page again.

## 6. W3C validation for the report

1. Go to the [W3C Nu HTML Checker](https://validator.w3.org/nu/).
2. Choose **Check by URL**.
3. Paste your live Home page URL.
4. Check all five pages and fix any errors it finds.
5. Take screenshots of the final results for your report.
